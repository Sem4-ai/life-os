# Notion

Notion - внешний интерфейс Life OS для просмотра проектов на iPhone и Mac.

Источник правды остается в markdown, Todoist и календаре. Notion пока только зеркало/панель.

## Что будет в Notion

- Страница `Life OS Projects`.
- Отдельная страница на каждый рабочий проект.
- Внутри проекта:
  - статус;
  - дедлайн;
  - результат;
  - следующий шаг;
  - задачи Todoist;
  - риски;
  - открытые вопросы;
  - последние решения;
  - связанные события календаря.

## Настройка

1. Создать страницу `Life OS` в Notion.
2. Создать Notion integration.
3. Дать integration доступ к странице `Life OS`.
4. В `.env` добавить:

```bash
NOTION_API_TOKEN=
NOTION_PARENT_PAGE_ID=
```

`NOTION_PARENT_PAGE_ID` - id страницы `Life OS` из URL.

## Sync

```bash
npm run lifeos -- notion sync
```

Команда создает/обновляет Notion-страницы из текущего состояния Life OS.

## Правило

Не редактировать Notion как источник правды. Если нужно поменять проект, задачу или решение, лучше сказать это ассистенту или внести в Life OS, затем запустить sync.
