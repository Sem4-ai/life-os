- Отвечать по-русски.

4. Заправщик проходит медосвидетельствование через автоматический аппарат.
5. Медицинская организация ставит в ЭПЛ отметку с электронной подписью.

## Telegram

Есть две интеграции.

### Telegram bot

Назначение:

- мобильный вход/выход LifeOS;
- обычный текст сохраняется в `inbox.md`;
- команды показывают `today`, календарь, проекты, inbox;
- можно добавлять и закрывать задачи.

Команды в Telegram:

```text
/today
/calendar
/projects
/inbox
/task текст задачи
/done текст задачи
/note текст заметки
/id
```

### Telegram user monitor через Telethon

Назначение:

- мониторить личные входящие сообщения;
- мониторить группы, где пользователя явно упомянули или ответили на его сообщение;
- агрегировать сообщения в `.private/telegram-review.md`;
- не отправлять ответы автоматически;
- ассистент потом предлагает ответы.

Правило уверенности:

- если контекста мало или уверенность ответа ниже 90%, сначала смотреть LifeOS-контекст, календарь, проекты и договоренности;
- если после поиска уверенность вышла на плато, явно назвать, чего не хватает;
- не имитировать уверенность числом без оснований.

Технический статус на 2026-06-15:

- Telethon установлен.
- Для этой машины нужен `use_ipv6=True`, потому что IPv4 к Telegram DC блокировался.
- В код добавлен `TELEGRAM_USE_IPV6=true`.
- Последняя проверка: `telegram-user status` показывает `Authorized: no`.
- Следующий шаг: выполнить `npm run lifeos -- telegram-user login`, ввести код Telegram и, если нужно, 2FA пароль.
- Очередь: `.private/telegram-review.md`.
- `.private/` в `.gitignore`.

## Важные ограничения

- Не выводить `.env`.
- Не выводить токены, API keys, session-файлы Telegram, SSH-ключи.
- Не пушить приватные переписки и session-файлы в git.
- `.private/` должен оставаться локальным.
- Не усложнять систему ради архитектуры.
- Если факт устаревший или не подтвержден, помечать это.
- Календарь в текущем файле может быть устаревшим, нужен `calendar sync`.
- Health-интеграция еще без реальных данных.
- Telegram Telethon еще не авторизован.
