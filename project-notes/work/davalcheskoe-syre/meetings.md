Итоги:
- Нулевая сумма по тикету/заказ-наряду для давальческого сырья признана проблемной: так реальные расходы по машине пропадают из управленческого учета.
- Для текущего периода договорились считать, что тикет по давальческому сырью должен закрываться суммой запчастей.
- Давальческое сырьё нужно размечать отдельно, чтобы оно не искажало количество заездов и средний чек ремонта.
- Временный вариант: отдельный тикет Drive Repair/Drive Service, связанный с исходной ремонтной заявкой, с компонентой `давальческое сырьё`.
- Целевой вариант требует проработки: стоимость давальческого сырья лучше относить в основной ремонтный тикет отдельным полем и протягивать в дашборды как отдельную категорию расходов Drive Service.
- Перед процессными изменениями нужно зафиксировать юридическую/налоговую сторону.

Решения:
- Не закрывать учет давальческого сырья нулем, если нужно видеть реальные расходы по машинам.
- Временная разметка: создать компоненту `давальческое сырьё`.
- Тикеты по давальческому сырью должны быть связаны с исходной заявкой/ремонтным тикетом.
- Сходить с Цапуриным и определить, как такие тикеты/расходы должны попадать в дашборды.
- Провести отдельную встречу/синк с юристами по юридической и налоговой стороне.

Следующие действия:
- Катя: завести компоненту `давальческое сырьё`.
- Семён + Катя: сходить к Цапурину по дашбордам и аналитике.
- Семён: участвовать во встрече с юристами по юридической/налоговой стороне.
- Ибрахим: донести временную инструкцию до делопроизводителей Drive Service.
- Команда: определить целевую схему связи тикетов и учета стоимости.
