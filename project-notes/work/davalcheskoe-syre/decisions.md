# Давальческое сырьё / Решения

## Принятые решения

- Давальческое сырьё не должно учитываться нулем, если цель - видеть реальные расходы по машине.
- На текущем этапе тикет по давальческому сырью должен закрываться суммой запчастей.
- Временно заводим/используем отдельную компоненту `давальческое сырьё` для разметки таких тикетов.
- Тикет по давальческому сырью должен быть связан с исходной ремонтной заявкой/тикетом.
- Перед финальным процессом нужно отдельно согласовать юридическую/налоговую сторону.

## Открытые решения

- Целевая схема учета: отдельный тикет или отдельное поле стоимости давальческого сырья в основном ремонтном тикете.
- Как исключать тикеты давальческого сырья из количества заездов и средней стоимости ремонта, но сохранять сумму затрат.
- Какой тип/вид ремонта или категория должна использоваться для аналитики Цапурина.
- Как автоматизировать связь с исходной заявкой: номер заявки, робот, подзадача или другой механизм.
- Кто финально владеет инструкцией для делопроизводителей Drive Service и запчастистов.
