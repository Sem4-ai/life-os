# Meeting Inbox

Входящий слой для рабочих встреч.

## Зачем

Сюда попадают сырые расшифровки встреч с iPhone. После обработки важное переносится в проект:

- `project.md` - новый контекст, участники, риски, открытые вопросы.
- `meetings.md` - краткое саммари встречи.
- `decisions.md` - зафиксированные решения.
- `decomposition.md` - декомпозиция и следующие шаги.
- Todoist - только конкретные действия.

## Как пользоваться с iPhone

1. Запиши встречу на iPhone.
2. Получи текстовую расшифровку.
3. Открой Obsidian -> `meeting-inbox`.
4. Создай заметку по шаблону или попроси ChatGPT создать ее командой:

```bash
npm run lifeos -- meeting new epl "Статус и блокеры"
```

5. Вставь расшифровку в раздел `Сырая расшифровка`.
6. Напиши ChatGPT: `Обработай meeting-inbox/<имя файла>.md`.

## Правило

Сырые расшифровки остаются здесь. В проектные файлы переносится только полезная выжимка: контекст, саммари, решения, открытые вопросы и задачи.
